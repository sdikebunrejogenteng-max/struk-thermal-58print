STRUK THERMAL 58 - PWA OFFLINE

ISI:
- index.html
- manifest.json
- sw.js
- icon-192.png
- icon-512.png

CARA PASANG:
1. PWA perlu dibuka dari alamat HTTPS (atau localhost) agar service worker dapat dipasang.
2. Upload folder ini ke hosting HTTPS seperti GitHub Pages/Netlify/Cloudflare Pages.
3. Buka alamatnya sekali saat online.
4. Pilih "Tambahkan ke Layar Utama"/"Install app".
5. Setelah ter-cache, aplikasi dapat dibuka tanpa internet.

CATATAN:
- Data transaksi tersimpan di browser/perangkat (localStorage).
- Backup JSON disarankan dilakukan berkala.
- Cetak memakai dialog print browser. Bluetooth thermal langsung dari browser tergantung dukungan perangkat/browser.
